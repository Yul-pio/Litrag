# RAG 基础

## 什么是 RAG

RAG 的全称是检索增强生成（Retrieval-Augmented Generation）。它的做法是：先从外部知识库里检索出与问题相关的片段，再把这些片段作为上下文交给大模型生成回答。它主要解决大模型的两个问题：一是不知道你的私有数据，二是容易在没有依据的情况下编造事实。

## 三个阶段

一个典型的 RAG 系统分为三步：索引、检索、生成。索引阶段把文档切块、向量化并写入存储；检索阶段根据用户问题召回最相关的若干块；生成阶段把召回结果拼进提示词，让模型基于证据作答。工程上，索引是一次性离线任务，检索和生成是在线请求，两者的优化目标并不相同。

## 为什么需要引用

学术场景对事实错误零容忍。因此回答里的每个结论都应当能追溯到原文的具体段落，这就叫引用溯源。没有引用溯源的 RAG，本质上还是一个更长的提示词，用户无法判断哪句话有依据、哪句话是模型自己补的。
