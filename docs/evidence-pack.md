# 复试文献证据包

## 这是什么

它不是自由聊天，而是一个固定的复试准备工作流：

```text
选择一篇论文
→ 填写目标学校、专业、导师方向
→ 生成研究问题、方法、实验、局限和贡献
→ 生成 3/5/8 分钟汇报提纲
→ 生成可能追问
→ 每条内容保留原文页码
→ 导出 Markdown 证据包
```

不依赖大模型，适合先作为人工交付工具使用。

## 使用步骤

1. 打开首页的“复试证据包”。
2. 上传导师论文，或从精选演示库选择一篇。
3. 填写目标学校、专业、导师姓名和研究方向。
4. 选择使用场景和汇报时长。
5. 点击“生成证据包”。
6. 点击“编辑”，直接修改总结、章节证据、汇报提纲和追问。
7. 点击“保存修改”，当前会话刷新后会自动恢复。
8. 点击“标记已核对”，记录人工检查状态。
9. 核对右侧原文证据和页码，导出编辑后的 Markdown 或复制全文。

“复制人工精修需求”会生成一份需求清单，方便你发送给运营者或客户确认。

## 当前能保证什么

- 所有证据来自上传论文或演示库
- 每个证据点保留文档、页码和原文
- 不调用大模型，不需要 API Key
- 不完整的章节会明确标记“需要人工补读”
- 编辑后的证据包保存在当前会话，24 小时内可恢复

## 当前不能保证什么

- 不能自动把英文长句改写成流畅的中文
- 不能保证自动识别每个论文的真实章节标题
- 不能替代人工判断论文创新点和复试表达
- 表格、公式和双栏 PDF 仍可能产生噪声

因此当前定位是“复试材料初稿和证据工作台”，不是全自动面试教练。

## 数据边界

- 用户上传 PDF 保存在当前浏览器会话
- 默认 24 小时后自动清理
- 不要上传未公开或涉密论文
- 演示论文按 `data/demo_papers.json` 从 arXiv 下载，PDF 不提交到 Git
